# نظام إدارة معاملات وسير وثائق الحج والعمرة (نسخة GitHub Pages)

نسخة مستقلة بنسبة 100% تعمل بالكامل داخل المتصفح، ومصممة خصيصاً للاستضافة المباشرة والمجانية على **GitHub Pages** دون الحاجة لأي خوادم أو منصات خارجية.

---

## الميزات الرئيسية
- 🕋 **إدارة دورة معاملات الحج والعمرة بالكامل**: من مرحلة المسودة والتقديم، تدقيق المستندات، إدخال رقم مجموعة نسك، الإحالة للوكيل السعودي، وحتى الإصدار والإتمام.
- ⚡ **لا تتطلب خوادم (100% Serverless)**: قاعدة بيانات محلية داخل المتصفح باستخدام `LocalStorage` و `IndexedDB` لتخزين الملفات والجوازات والمعاملات.
- 🌐 **استضافة مجانية على GitHub Pages**: تدعم التحديثات التلقائية عبر GitHub Actions أو النشر المباشر عبر مجلد `docs`.
- 🔄 **تصدير واستيراد البيانات (JSON Backup)**: إمكانية حفظ واستعادة البيانات ونقلها لأي جهاز.
- 👥 **أدوار وصلاحيات متكاملة**:
  - مرسل المعاملات (`sender` / `Sender@123456`)
  - موظف تسجيل الصفا (`safa_emp` / `Safa@123456`)
  - الوكيل السعودي (`saudi_agent` / `Agent@123456`)
  - مدير النظام (`admin` / `Admin@123456`)

---

## التشغيل المحلي للتطوير
```bash
npm install
npm run dev
```

## البناء للإنتاج والاستضافة
```bash
npm run build:docs
```
