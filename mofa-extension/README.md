# مساعد تأشيرات وزارة الخارجية السعودية (MOFA Visa Helper) 🇸🇦

إضافة متصفح Google Chrome خفيفة مخصصة للربط المباشر مع نظام إدارة رحلات العمرة.

## ✨ المميزات:
1. **تعبئة آلية فورية:** بمجرد الضغط على زر الاستعلام في نظام العمرة، تفتح صفحة الوزارة وتُعبأ بيانات المسافر (رقم الجواز، الاسم الأول، الجنسية) تلقائياً.
2. **التركيز على الكابتشا:** تركز الشاشة مباشرة على حقل رمز التحقق المرئي (الكابتشا) لتكتب الأرقام فقط وتضغط بحث.
3. **التقاط التأشيرة وربطها:** بمجرد صدور التأشيرة، تلتقط الإضافة رقم التأشيرة وملفها الرسمي وترسله فوراً لنظام العمرة ليتم حفظه وربطه ببطاقة المسافر وإغلاق النافذة آلياً.

---

## 🚀 طريقة التثبيت في متصفح Google Chrome (في دقيقة واحدة):

1. افتح متصفح Google Chrome واكتب في شريط العنوان:
   ```
   chrome://extensions
   ```
   ثم اضغط Enter.

2. في أعلى اليمين (أو اليسار حسب لغة المتصفح)، قم بتفعيل زر:
   **"وضع مطوّر البرامج" (Developer mode)**.

3. اضغط على الزر الجديد:
   **"تحميل حزمة غير مضغوطة" (Load unpacked)**.

4. اختر هذا المجلد (`mofa-extension`).

5. مبروك! ستظهر الإضافة باسم **"مساعد استعلام تأشيرات وزارة الخارجية (MOFA Helper)"** وستعمل تلقائياً فوراً.
