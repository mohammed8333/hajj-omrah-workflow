# 🕋 إضافة متصفح Chrome: مساعد استعلام تأشيرات وزارة الخارجية بالذكاء الاصطناعي (MOFA AI)

تعتمد هذه الإضافة على تقنية الذكاء الاصطناعي **(Google Gemini Vision)** لقراءة رموز التحقق (الكابتشا) آلياً وتعبئة بيانات المسافرين وحفظ وطباعة التأشيرة الرسمية بنقرة واحدة بدون أي تدخل يدوي وبدون أي تكلفة سيرفرات.

---

### طريقة التثبيت في متصفح Google Chrome (في دقيقة واحدة):

1. فك الضغط عن ملف `mofa-extension.zip`.
2. افتح متصفح Google Chrome وانتقل إلى: `chrome://extensions`
3. قم بتفعيل **وضع مطور البرامج (Developer Mode)** في الزاوية العلوية.
4. اضغط على زر **تحميل تم فك حزمته (Load unpacked)**، واختر مجلد `mofa-extension`.
5. مبروك! الإضافة أصبحت جاهزة وتعمل في الخلفية.

---

### كيف تعمل الإضافة؟
1. عند الضغط على زر **استعلام التأشيرة الذكي (AI 🇸🇦)** بجوار أي مسافر داخل النظام.
2. تفتح صفحة الوزارة، وتقوم الإضافة بتعبئة:
   - رقم الجواز.
   - الاسم الأول.
   - الجنسية (مصر).
3. يقرأ نموذج الذكاء الاصطناعي (Gemini Vision) رمز الكابتشا ويكتبه فوراً في ثانية واحدة.
4. عند ظهور التأشيرة، توفر لك الإضافة:
   - زر **💾 حفظ وربط التأشيرة بالمعاملة فوراً**.
   - زر **🖨️ طباعة التأشيرة كـ PDF رسمي** (مع تثبيت ألوان التحذير والألوان الرسمية).
